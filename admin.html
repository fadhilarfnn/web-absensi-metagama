Cara Deploy & Dapatkan Link Publik (GRATIS)

Saat ini form berjalan lokal di komputer Anda. Agar mahasiswa bisa mengaksesnya lewat HP, Anda perlu meng-upload ke internet. Berikut cara termudah:

Opsi 1: Netlify Drop (Paling Mudah, Tanpa Akun)
  1. Buka https://app.netlify.com/drop di browser Anda.
  2. Seret (drag & drop) seluruh folder D:\percobaan antigrafity ke area upload di halaman tersebut.
  3. Tunggu beberapa detik. Netlify akan memberikan link publik (misal: https://random-name.netlify.app).
  4. Link tersebut adalah link index.html yang bisa Anda share ke mahasiswa!
  5. Link admin Anda: tambahkan /admin.html di belakang URL (misal: https://random-name.netlify.app/admin.html). Jangan bagikan link ini!
Opsi 2: GitHub Pages (Gratis, Permanen)
  1. Buat akun GitHub jika belum punya.
  2. Buat Repository baru (misal: presensi-polban), lalu upload semua file dari D:\percobaan antigrafity.
  3. Masuk ke Settings → Pages, pilih branch main, lalu simpan.
  4. Link publik Anda: https://username.github.io/presensi-polban/

Integrasi Google Sign-In (Login Mahasiswa)

Agar mahasiswa wajib masuk dengan email institusi POLBAN sebelum mengisi form presensi, dapatkan Google Client ID secara gratis dengan langkah ini:

  1. Buka Google Cloud Console.
  2. Buat Project baru, cari "APIs & Services" -> "OAuth consent screen". Konfigurasikan screen untuk User Type External/Internal, isi info dasar aplikasi.
  3. Masuk ke menu "Credentials" -> Klik "+ Create Credentials" -> pilih "OAuth client ID".
  4. Pilih Application Type: Web application.
  5. Pada bagian "Authorized JavaScript origins", klik Add URI, lalu masukkan URL website/form Anda (misal: http://localhost:8080 dan https://[nama-web-anda].netlify.app).
  6. Klik Create, lalu salin Client ID yang diberikan (berakhiran .apps.googleusercontent.com) dan tempel di bawah ini.
Jika kolom ini dikosongkan, halaman mahasiswa akan menggunakan Simulasi Login Google tiruan (sangat cocok untuk uji coba lokal).

Integrasi Google Sheets

Agar data presensi mahasiswa otomatis masuk ke Google Sheets, ikuti langkah berikut:

  1. Buka Google Sheets baru.
  2. Klik menu Ekstensi → Apps Script.
  3. Hapus kode default, lalu salin-tempel seluruh isi file google_apps_script.js yang ada di folder proyek Anda. Simpan.
  4. Klik Deploy → New deployment. Pilih type Web app. Set akses ke "Anyone". Klik Deploy.
  5. Salin URL Web App yang diberikan, lalu tempel di kolom di bawah ini.
URL ini akan disimpan ke file config.js. Setelah mengubahnya, klik Simpan lalu re-upload/deploy ulang folder proyek Anda.

Cara Publikasi ke Internet (Hosting)

Gunakan layanan hosting gratis untuk mempublikasikan form agar bisa diakses seluruh mahasiswa lewat smartphone:

1. GitHub Pages (Direkomendasikan)
  1. Repo Anda sudah terhubung ke GitHub: https://github.com/fadhilarfnn/web-absensi-metagama
  2. Buka repositori di GitHub -> Menu Settings -> Pages.
  3. Pilih Branch: main, Folder: / (root) -> Klik Save.
  4. Web akan online di https://fadhilarfnn.github.io/web-absensi-metagama/.
2. Authorized JavaScript Origins di Google Cloud

Pastikan domain di atas sudah ditambahkan pada Authorized JavaScript Origins di Google Cloud Console agar Google Sign-In tidak memunculkan Error 400: origin_mismatch.
